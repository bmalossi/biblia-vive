01 — Análise do Concorrente
O que o BíbliaOnline.com.br
acerta e erra
Após estudar o site líder, identificamos pontos críticos de UX que afastam o usuário de uma experiência de leitura profunda e contemplativa.
⚠ Problema Crítico

Anúncios interrompem a leitura

Publicidade no meio do texto sagrado cria dissonância cognitiva severa. O usuário perde o fluxo de leitura toda vez que um anúncio aparece.

⚠ Problema Crítico

Homepage poluída

Dezenas de seções competindo por atenção. O usuário que quer apenas ler um capítulo tem que scrollar muito antes de chegar ao conteúdo.

⚠ Problema Crítico

Navegação entre capítulos fragmentada

Não há uma barra persistente de capítulos. Voltar ao índice de capítulos requer múltiplos cliques e recarregamentos de página.

⚠ Problema Sério

Nenhum modo de leitura focada

Não existe opção para esconder tudo exceto o texto. Elementos de navegação, rodapés e sidebar distraem durante a leitura.

⚠ Problema Sério

Ferramentas de estudo desconectadas

Para estudar um versículo, o usuário precisa abrir outra aba ou sair da página. Não há painel de estudo integrado à leitura.

⚠ Problema Sério

Typography inadequada para leitura longa

Fontes sem serifa, tamanho pequeno e line-height apertado. Leitura de capítulos longos se torna fatigante em minutos.

✓ Acerto

150+ versões disponíveis

Excelente cobertura de traduções. É um diferencial real que deve ser mantido e melhorado na interface de seleção.

✓ Acerto

Recursos bíblicos complementares

Devocionais, estudos por tema e artigos agregam valor. A ideia é boa, porém a execução interfere com a jornada principal de leitura.

✓ Acerto

Versículo do dia

Ponto de entrada emocional valioso para usuários recorrentes. Deve ser mantido mas de forma muito mais elegante e discreta.

02 — Princípios de Design
As 6 leis que governam
cada decisão de design
Cada pixel, cada interação e cada feature é filtrado por esses princípios. Se não passa pelo filtro, não entra.
01

O texto é sagrado

Nada compete com o texto bíblico. UI, anúncios, notificações e elementos decorativos sempre ficam subordinados ao conteúdo.

02

Zero fricção para ler

Do momento que o usuário chega ao site até o primeiro versículo lido: máximo 2 cliques. Sempre.

03

Onde estou, nunca me perco

O usuário sabe exatamente em que livro, capítulo e versículo está, em qualquer tela e tamanho de dispositivo.

04

Estudo integrado, não separado

Ferramentas de estudo aparecem onde e quando o usuário precisa, sem sair da página ou interromper o fluxo.

05

Acessibilidade não é opcional

Funciona perfeitamente para idosos, pessoas com baixa visão, daltonismo, e usuários com dispositivos antigos.

06

Mobile first, sempre

80% dos acessos são mobile. Cada decisão começa pela tela do celular e expande para desktop — nunca o contrário.

Estrutura de navegação
ultra-clara
A hierarquia é simples: máximo 3 níveis de profundidade para acessar qualquer conteúdo. Sem labirintos.

06 — Features Diferenciadoras
O que nenhum outro
site bíblico tem
Features que transformam uma leitura passiva em estudo ativo — todas integradas na experiência principal, sem abas extras.
🤖

Assistente de Estudo com IA

Selecione qualquer versículo e pergunte: "O que significa este versículo?", "Qual o contexto histórico?", "Como outros livros falam sobre isto?" A IA responde no painel lateral.

⇄

Comparação paralela de versões

Até 4 traduções lado a lado, com diferenças destacadas automaticamente. Sincronização de scroll entre colunas. Disponível para 150+ versões.

🗺️

Mapa de leitura interativo

Visualize onde você está na Bíblia como um todo. Um mapa visual mostra o progresso, capítulos lidos, livros concluídos — como um videogame.

✎

Notas e destaques pessoais

Anote em qualquer versículo. Destaque com 5 cores diferentes. Exporte para PDF, Notion ou WhatsApp. Sincronização cross-device via conta gratuita.

🔗

Referências cruzadas visuais

Versículos conectados aparecem visualmente. Clique em um versículo para ver uma teia de referências relacionadas em outros livros — navegação sem perder o contexto.

♪

Áudio com Text-to-Speech nativo

Ouça o capítulo com voz natural em PT-BR. Controle de velocidade, voz masculina/feminina. Ideal para dirijir ou fazer exercícios enquanto lê.

📅

Planos de leitura personalizados

Bíblia em 1 ano, NT em 90 dias, Salmos em um mês, ou crie o seu. Notificações gentis, sem pressão. Progresso visual como um streak.

♿

Acessibilidade de primeiro nível

Fonte OpenDyslexic, alto contraste WCAG AAA, tamanho de fonte de 12 a 32px, compatível com leitores de tela, navegação 100% por teclado.

📤

Compartilhamento rico

Gere um card visual bonito do versículo para Instagram, WhatsApp ou Twitter. Fundo com textura de papel, tipografia cuidada, pronto para postar.

07 — Stack Técnica Recomendada
Tecnologia a serviço
da experiência
Escolhas técnicas que garantem performance de 100ms de carregamento, offline-first e zero dependência de conexão para quem já visitou.
Frontend
  • Next.js 15 (App Router)
  • React 19 + TypeScript
  • Tailwind CSS v4
  • Framer Motion (animações)
  • Radix UI (acessibilidade)
Performance
  • ISR — geração estática por capítulo
  • Service Worker (offline-first)
  • Route prefetching automático
  • Edge Functions (Vercel/CF)
  • Core Web Vitals: todos verdes
Backend / Dados
  • PostgreSQL + Prisma ORM
  • API REST + tRPC
  • Redis para cache de versículos
  • 150+ versões bíblicas em JSON
  • Full-text search com Postgres
IA & Estudo
  • Claude API (Anthropic)
  • RAG com corpus bíblico
  • Embeddings para cruzamentos
  • TTS com ElevenLabs / Web Speech
  • Cache de respostas frequentes
Conta & Sync
  • Auth: NextAuth v5
  • Login via Google / Email
  • Notas em Supabase Realtime
  • Export: PDF, JSON, Markdown
  • PWA instalável no celular
Analytics & SEO
  • Metadata dinâmica por versículo
  • Structured Data (Bible markup)
  • Sitemap auto-gerado (31k+ páginas)
  • Posthog (analytics ético)
  • Lighthouse score alvo: 100
