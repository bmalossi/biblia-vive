SPRINT 00-A
Dados bíblicos & Decisões técnicas
Dias 1–3
  • 📦
    Baixar Bible API open-source (API.Bible ou scripture.api.bible)
    Gratuita até 5.000 req/dia · Tem ACF, ARA, NVI, KJV e mais
  • 📄
    Preparar JSON local com os 66 livros + capítulos + número de versículos
    Isso vira o "índice" offline da navegação
  • 🎨
    Definir tokens de design: cores sépia/dark, fontes Lora + DM Sans
    Criar arquivo design-tokens.css para usar no Lovable
  • 🔑
    Criar conta na API.Bible e gerar chave de API
    Guardar no .env: VITE_BIBLE_API_KEY=...
  • 📁
    Definir estrutura de URL do site
    /[versao]/[livro]/[capitulo] → ex: /acf/jo/3
Entrega
API key configurada · JSON de índice bíblico pronto · Tokens de design definidos

L
Prompt de início para o Lovable
Crie um projeto de site de leitura da Bíblia chamado "Bíblia Viva". Stack: React + TypeScript + Tailwind CSS + React Router v6. Fontes: Lora (serif, para texto bíblico) e DM Sans (sans-serif, para UI). Estrutura de rotas inicial: - "/" → Homepage - "/:versao/:livro/:capitulo" → Página de leitura (ex: /acf/jo/3) - "/busca" → Busca Crie um arquivo src/lib/bibleApi.ts com uma função fetchChapter(version, book, chapter) que consome a API https://api.scripture.api.bible/v1/ com a chave em import.meta.env.VITE_BIBLE_API_KEY. Paleta de cores no tailwind.config.js: - parchment: '#f8f4ed' (fundo) - gold: '#9a6e1e' (primário) - ink: '#2a2218' (texto) - muted: '#9a8c78' (texto suave)
💡 Dica: Seja específico sobre stack e rotas logo no primeiro prompt. Mudar o roteamento depois no Lovable é trabalhoso.

Prompts-chave para o Lovable no Sprint 2 (Tela de Leitura)
Crie a página de leitura de capítulo em src/pages/ReadingPage.tsx. Layout: header com breadcrumb (Versão · Livro · Capítulo), área de texto central com max-width 680px centralizado, painel lateral de 280px (oculto no mobile). Para cada versículo, renderize: - Número do versículo em DM Mono, dourado, 0.65rem - Texto em Lora, 1.05rem (ou variável do user preference), line-height 1.85 - Ao clicar no versículo: exiba um floating toolbar com os botões: "Copiar", "Destacar", "Anotar", "Compartilhar" Navegação: no rodapé, botões "← Capítulo Anterior" e "Próximo Capítulo →" centralizados. Atalhos de teclado: ArrowLeft = capítulo anterior, ArrowRight = próximo. Dados: consumir a função fetchChapter() já criada em src/lib/bibleApi.ts

Prompt para integração da IA no Lovable
Crie uma Supabase Edge Function chamada "bible-ai" que: 1. Recebe: { verseRef, verseText, question } via POST 2. Chama a Anthropic API (claude-sonnet-4-20250514) com o contexto do versículo 3. Retorna a resposta em streaming (text/event-stream) System prompt: "Você é um assistente de estudo bíblico em português. Responda com base no versículo fornecido. Seja claro, profundo e acessível. Máximo 200 palavras por resposta." No frontend (StudyPanel.tsx): - Exiba 3 botões de ação rápida: "Explicar", "Contexto histórico", "Aplicação prática" - Campo de texto para perguntas livres - Renderize a resposta com streaming (typewriter effect) - Mostre contador: X/10 perguntas grátis hoje
