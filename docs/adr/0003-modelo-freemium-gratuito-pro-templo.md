# Modelo freemium com três camadas: Gratuito, Pro e Templo

O produto oferece acesso gratuito ilimitado à leitura bíblica e às funcionalidades core (planos, notas, destaques). Funcionalidades avançadas (ex.: exportação PDF) requerem o plano Pro. O plano Templo é B2B, destinado a igrejas, e desbloqueia o Modo Igreja (projeção de versículos). Templo é um superconjunto de Pro.

Essa decisão é deliberada e alinhada à missão: a Bíblia nunca deve estar atrás de um paywall. Monetizar apenas o extra — e não o essencial — é um princípio de produto, não um detalhe de precificação.

## Consequences

- Nenhum conteúdo bíblico (texto, planos de leitura, notas básicas) pode ser movido para trás do paywall em versões futuras sem contradizer este ADR.
- O plano Templo não deve ser vendido para pessoas físicas; se isso mudar, rever o modelo de acesso ao Modo Igreja.
