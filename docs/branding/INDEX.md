# Introdução

Este documento apresenta a estrutura completa do Projeto Logos.

Seu objetivo é servir como referência para pessoas, equipes e agentes de Inteligência Artificial, preservando a organização, a navegabilidade e a evolução da documentação institucional da Bíblia Vive.

Sempre que um documento for criado, removido, aprovado ou arquivado, este índice deverá ser atualizado.

# Convenções

Toda documentação do Projeto Logos deverá seguir os seguintes princípios.

- Cada documento possui uma responsabilidade única.
- Não há duplicação de conteúdo entre domínios.
- Mudanças estruturais exigem um Brand Decision Record (BDR).
- Documentos devem permanecer independentes de tecnologias específicas.
- A arquitetura é organizada por domínios de conhecimento.
- O Projeto Logos documenta princípios permanentes, não processos operacionais.
