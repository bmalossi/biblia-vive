BDR-0001

Título:
O diretório principal permanecerá /docs/branding

Status:
Accepted

Contexto:
Foi proposta a alteração para /docs/logos para representar um sistema de conhecimento organizacional.

Decisão:
Manter /docs/branding como diretório raiz.

Justificativa:
A nomenclatura "branding" comunica imediatamente seu propósito para qualquer colaborador, desenvolvedor ou agência que acesse o repositório pela primeira vez. A clareza semântica foi considerada mais importante do que uma nomenclatura conceitualmente mais sofisticada.

Consequência:
O Projeto Logos permanece como nome do projeto de construção da marca, enquanto /docs/branding permanece como seu local de armazenamento.
